Hello, this is just a silly project I decided to create for myself and friends, nothing too crazy

Includes

!whoami (prints discord handle of user)
!wheel (allows users to choose between things with a small animation)
!speed (speed gifs if anyone types "speed")
Welcome/Goodbye messages

More features as I think of them/need them

🤖 Bot Guide — How to Use

All commands start with: !


🎡 Wheel Command

Spin a decision wheel between options.

Usage:

!wheel pizza, burgers, tacos

What it does:

Spins your choices
Randomly selects one winner
Shows a live spinning animation
🎲 Roll Command

Roll a random number between 1–100.

Usage:

!roll
😎 Hello Command

Just a simple greeting.

Usage:

!hello
👤 Who Am I

Shows your username.

Usage:

!whoami
📡 Ping Test

Checks if the bot is online.

Usage:

!ping
⚙️ Server Setup Commands
👋 Set Welcome Channel (Admin Only)

Sets where welcome messages go when someone joins.

Usage:

!setwelcome #channel-name

Example:

!setwelcome #general

What it does:

Saves your server’s welcome channel
Sends join/leave messages there automatically
🎉 Automatic Features
👋 Welcome Messages

When someone joins:

Bot sends a greeting in your selected channel

Example:

👁️ Welcome to heaven, @user!

👋 Goodbye Messages

When someone leaves:

👁️ username left.

⚡ iShowSpeed gifs

If someone types the word:

speed

The bot automatically sends a random GIF. 

🧠 Tips
Use commas in !wheel commands
Only admins can set the welcome channel
Bot must be online for features to work
Make sure it has permission to send messages in channels
